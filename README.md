# Student Management System

A console-based Java application developed to manage student records efficiently.

## 🚀 Features
- **Add Student:** Register new student with ID, Name, Course, and Marks.
- **View Students:** Display all student records in a tabular format.
- **Search Student:** Find student details using their unique ID.
- **Delete Student:** Remove student records from the system.
- **Data Validation:** Input verification for ID, names, and marks range.

## 🛠️ Technologies Used
- **Language:** Java (JDK 8+)
- **Concepts:** Object-Oriented Programming (OOP), Encapsulation
- **Collections:** ArrayList
- **Input Handling:** Scanner
